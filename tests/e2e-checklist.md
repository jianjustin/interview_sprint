## 1. 逐项核对

建议顺序：在工具 A 里完成 C1–C6、C8、C10，换到工具 B 做 C7；再在任一工具里做一次经历复盘主题（C11）；最后跑 C9。

### C1 先给大纲，确认前不建文件
- **怎么做**：在空目录里调用 skill，主题「设计一个实时计费系统」。
- **期望**：对话里给出大纲——每课一行（标题 + 一句话），非重点课标「可选」，最后一课是「面试串讲」，附拟定 slug；并问你是否确认。
- **判定**：此时 `ls -a` 看不到 `.interview_points/`。大纲能看出重点（有说明哪几课是重点，或主线 / 可选分明），而不是平铺知识点。

### C2 确认后生成文件并给出路径
- **怎么做**：回复「确认」。
- **期望**：生成 `.interview_points/<slug>/course.html`、`course-data.js`、`.interview_points/index.html`、`index-data.js`；给出课程页**绝对路径**（能执行 shell 时会尝试自动打开浏览器）。
- **判定**：`ls .interview_points/<slug>/` 有两个文件；双击 `course.html` 能打开并显示大纲；`index.html` 能列出该主题。

### C3 分段讲，每段停下
- **怎么做**：说「开始第一课」，连续听 3 段以上（中间说「继续」）。
- **判定标准**：
  - 单段正文约 300 字以内（不计代码 / 简图），最多一张简图；
  - 每段末尾明确停下、留出插话机会（如「有疑问吗？没有的话我接着讲 xx」），**不会**一次输出整课；
  - 停顿的措辞不是每段完全相同。

### C4 穿插面试题，先让你试答
- **判定标准**：
  - 一课之内至少出现一次「面试官可能会问：……」；
  - 出题后**先停下**等你作答（或等你说「直接讲」），而不是同一条消息里直接给出答案；
  - 你作答后，agent 先点评，再讲思路和参考回答。

### C5 插话问题进入「你问过的」
- **怎么做**：在讲课中途插问一个问题（如「预扣之后计价算错了怎么办？」）。
- **判定**：agent 先回答再接回；本课结束后，课程页这一课出现「你问过的」卡片，包含该问题和回答要点。

### C6 页面随课程更新
- **判定**：
  - 开课时（agent 开始讲之前或刚开始讲时）课程页在几秒内出现本课新增的生长元素（高亮 + 「本课新增」标签），无需手动刷新；
  - 课末本课卡片写入（至少「要点」「面试怎么讲」），左侧状态变为「已学」，下一课变为「进行中」。

### C7 换工具续学
- **怎么做**：退出工具 A，在**同一目录**启动工具 B，说「继续计费系统」（或无参数调用 skill 后选择主题）。
- **判定**：agent 读取 `course-data.js` 后用两三句话回顾（学到哪、上次讲到什么，`review` 有内容时会提到），然后从 `resume` 处继续，而不是从头开始或重新开题。

### C8 中途增删课程不影响已学内容
- **怎么做**：说「在第 3 课后面加一课『幂等设计』」，再说「删掉可观测性那一课」。
- **判定**：agent 先给出调整后的大纲并确认；课程页上已学课程的卡片和生长图完全不变（点开已学课程逐一对比），新课出现在正确位置。

### C9 course.html 从未被修改
- **怎么做**（整个流程结束后）：
  ```bash
  bash /Users/chenjianrui/workspaces/skills/interview_sprint/tests/c9-hash-check.sh ~/isprint-e2e
  ```
- **判定**：所有行都是 `OK`，最后输出「C9 通过」，退出码 0。

### C10 不依赖工具专属能力
- **判定**：全程只有普通对话和读写文件（shell 只用于复制模板、打开浏览器等可选操作）；没有弹出选择框 / 表单、没有调用子 agent 或浏览器工具才能继续的步骤。打开浏览器失败时只给出路径。

### C11 经历复盘主题用示范案例
- **怎么做**：开一个新主题「讲述一次 SQL 调优过程」。
- **判定**：
  - agent **不追问**你的真实经历，直接构造示范案例出大纲；
  - 开题时在对话里说明「这是示范案例，请换成你自己的经历」；
  - 课程页页头下方有橙色提示条「示范案例，请换成你自己的经历」；
  - 讲到「面试串讲」时再提醒一次（可以说「跳到面试串讲」快速验证）。
